# 리포트 템플릿

순서는 고정이다. **결론 먼저, 근거 다음, 한계는 숨기지 않는다.**

Slack 스레드 응답은 **축약하되 생략하지 않는다.** 최소 구성은
`## 결론` / `## 인풋`(표 대신 한 줄 요약 가능) / `## 데이터 소스`(모델·필터·grain 한 줄) /
`## 건강성`(WARN 이상만) / `## 한계` / 재현 SQL 경로다.

`데이터 소스`와 재현 경로는 뺄 수 없다. 그 둘이 없으면 숫자를 검증할 방법이 사라진다.
문서(`reports/`)로 남기면 전 항목을 표로 채운다.

```markdown
# {분석 제목}

**모드**: {활동량 | 라이프사이클 단계 | 전후 비교 | 세그먼트 비교 | 리텐션/코호트 | 데이터 품질 진단 | 계측 공백 판정}
**as-of**: {데이터 기준일 YYYY-MM-DD}
**작성**: {실행일 YYYY-MM-DD}

## 결론

- 핵심 결론 1~3줄. 숫자에는 기간·분모·분자·grain을 붙인다.
- 인과 해석 가능 여부를 한 줄로 명시한다.
- 다음 액션 또는 이 결론으로 내릴 수 있는 의사결정.

## 인풋

| 항목 | 값 | 상태 | 근거 |
|---|---|---|---|
| 분석 대상 | | 확인됨/추론/미확인 | |
| 분석 단위(grain) | | | 모델명과 그 grain |
| 기간 (검증 / 본분석) | | | 보유 범위 확인 결과 |
| 기준 시간 | activity_date, UTC | | 컬럼명 |
| 대상 조건·세그먼트 | | | 필터 조건식 |
| 제외 조건 | automation_actor: 제외/포함, ... | | |
| 핵심 지표 1개 | | | 정의식. 쿼리 전 선언, 이후 변경 없음 |
| 가드레일 지표 | | | 없으면 `없음` |
| 스캔 예산 | 목표 / 실제 dry run | | |

`근거` 없는 `확인됨`은 반증 불가능한 주장이다. 빈칸으로 두지 않는다.

## 데이터 소스

| 지표 | 모델/테이블 | 조건 | grain | 비고 |
|---|---|---|---|---|

이름이 겹치는 모델이 있었다면 **왜 이 모델을 골랐는지** 한 줄 적는다.

## 핵심 결과

차트 또는 표. 차트 제목에 지표·grain·기간을 넣는다.

## 해석

- 관측된 패턴
- 가능한 설명 (복수로 적는다)
- 반례 또는 이 결론을 뒤집을 수 있는 것

## 한계

- 계측 공백
- 좌·우측 절단
- 표본 수
- 계절성·요일 효과·외부 요인
- 실험 설계 부재 (대조군 없음)
```

## 표현 규칙

숫자 하나를 쓸 때마다 네 가지를 붙인다. **기간, 분모, 분자, grain.**

```text
나쁨
전환율은 4.2%입니다.

좋음
2025-09-01 주 최초 관측 코호트 기준 W1 리텐션은 21.3%입니다.
분모는 그 주에 처음 관측된 actor 412,880명, 분자는 다음 주에 1회 이상 활동한 87,944명입니다.
소스는 metrics_retention_weekly(최초 관측 코호트)이며 자동화 actor는 제외하지 않았습니다.
좌측 절단 때문에 2025-05 코호트는 신규로 볼 수 없어 제외했습니다.
```

## 금지 표현

| 쓰지 말 것 | 대신 |
|---|---|
| "X 때문에 늘었다" | "X 이후 구간에서 같이 늘었다" |
| "유의하다" | 효과 크기와 표본 수 |
| "사용자 N명" (actor를 지칭할 때) | "actor N명 (봇 포함/제외)" |
| "커밋 N건" (event_count를 지칭할 때) | "PushEvent N건" |
| "이탈률 X%" (as-of 없이) | "as-of YYYY-MM-DD 기준 이탈 확정 에피소드의 X%" |
| "데이터가 없다" | "fact에는 없음 / raw에서 N GB 스캔하면 가능" |
| "차이가 없다" / "효과가 없다" (표본이 작을 때) | "표본이 작아 판단할 수 없다(검정력 부족). N을 얼마까지 늘리거나 기간을 얼마까지 넓히면 판단 가능" |
| 훑은 지표 중 움직인 것만 보고 | "지표 N개를 봤고 그중 1개가 움직였다. 사전에 고른 지표는 아니다" |
